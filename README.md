# nowakproduction.github.io

Public pages of the apps: guides, privacy policies, terms. Served by GitHub Pages from `main`.

- `monitorapp/` — MonitorApp (working name): guide (EN, `pl/`), `privacy/`, `terms/`.
  Generated by `python3 tools/build-monitorapp.py .` — edit the texts there, run it, commit.
  The app opens `https://nowakproduction.github.io/monitorapp/` (`websiteUrl` in the app's
  `app-identity.json`); a new product name means a new folder here and a new `websiteUrl` there.

Fonts: Geist (SIL OFL 1.1, `monitorapp/assets/fonts/OFL.txt`).
