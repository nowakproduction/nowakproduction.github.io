# nowakproduction.github.io

Public pages of the apps: guides, privacy policies, terms. Served by GitHub Pages from `main`.

- `multimonitor/` — MultiMonitor: guide (EN, `pl/`), `privacy/`, `terms/`.
  Generated by `python3 tools/build-multimonitor.py .` — edit the texts there, run it, commit.
  The app opens `https://nowakproduction.github.io/multimonitor/` (`websiteUrl` in the app's
  `app-identity.json`); a new product name means a new folder here and a new `websiteUrl` there.
- `monitorapp/` — redirects from the working name (until 2026-11-10).

Fonts: Geist (SIL OFL 1.1, `multimonitor/assets/fonts/OFL.txt`).
